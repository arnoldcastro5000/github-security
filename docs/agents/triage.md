# Triage notes

Repo-specific rules for `/triage`.

- **Labels**: the five triage labels (`docs/agents/triage-labels.md`) and the category labels
  `bug` and `enhancement` exist. Do not create others.
- **Wayfinder issues are not triaged.** An issue with a `wayfinder:*` label belongs to the map
  (issue #1). Never add a triage label to it, and leave it out of "needs attention".
- **External PRs** are not a request surface (`docs/agents/issue-tracker.md`).
- **Out of scope**: the map's "Out of scope" section lists what this effort excludes. There is
  no `.out-of-scope/` knowledge base yet; create it only when a request is first ruled out.
- **Public repo**: a triage comment must not name a private repo or hold a personal email.
- `gh` is 2.46: see `docs/agents/issue-tracker.md` for the commands that work.
